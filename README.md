# Titulo & Descrição Curta
 ## Calculadora de Média
** Programa em Python que calcula a média de uma lista de números. **

# Tecnologias Utilizadas
```bash
python --3,14 version
```


# Como instalar e executar
## Instalar
Acesse a página oficial do Python e baixe a versão mais recente para o seu sistema operacional.Abra o arquivo baixado para iniciar o instalador. Muito importante: Marque a caixa "Add Python to PATH" (ou Adicionar Python ao PATH) antes de clicar em instalar.

## executar
``` python app.py ```
